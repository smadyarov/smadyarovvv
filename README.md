## Калькулятор для Windows

Скачать готовую программу: https://github.com/smadyarov/smadyarovvv/releases/latest
(файл **Calculator.exe** — калькулятор с кнопками, Python не нужен).

Программа собирается автоматически через GitHub Actions при каждом изменении в ветке `master`.

- `gui_calculator/` — калькулятор с кнопками (Python, tkinter)
- `calculator-app/` — консольный калькулятор (Go)
- `calculator.py`, `hello.py` — первые программы на Python
